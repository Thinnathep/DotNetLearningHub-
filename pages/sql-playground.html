🏆 Challenge Missions (3 ภารกิจท้าทาย)

ฝึกเขียนคำสั่ง SQL จริงตามเงื่อนไขที่กำหนด เมื่อตรวจคำตอบถูกต้องจะได้รับ +50 XP ต่อข้อ!

1 ภารกิจที่ 1: กรองเงินเดือน
+50 XP

ค้นหาพนักงานที่มีเงินเดือนมากกว่า 40,000 บาท (salary > 40000) จากตาราง employees

💡 คำใบ้: SELECT * FROM employees WHERE salary > 40000;
2 ภารกิจที่ 2: INNER JOIN
+50 XP

ดึงข้อมูลพนักงานพร้อมชื่อแผนกด้วย INNER JOIN ระหว่างตาราง employees กับ departments โดยเชื่อมด้วย employees.dept_id = departments.id

💡 คำใบ้: SELECT * FROM employees INNER JOIN departments ON employees.dept_id = departments.id;
3 ภารกิจที่ 3: กรองสินค้าซอฟต์แวร์
+50 XP

หาสินค้าหมวดหมู่ 'Software' ที่มีราคามากกว่า 10,000 บาท (category = 'Software' AND price > 10000) จากตาราง products

💡 คำใบ้: SELECT * FROM products WHERE category = 'Software' AND price > 10000;

📖 สรุปไวยากรณ์ SQL สำคัญที่ควรรู้

💡 สรุปภาพรวมคำสั่ง SQL พื้นฐาน
Clause / คำสั่ง รูปแบบไวยากรณ์ (Syntax) คำอธิบายการทำงาน
SELECT ... FROM SELECT name, salary FROM employees; ระบุคอลัมน์และตารางที่ต้องการดึงข้อมูล
WHERE WHERE salary > 40000 AND dept_id = 1 กรองเฉพาะแถวที่ตรงตามเงื่อนไขเปรียบเทียบ
INNER JOIN ... ON JOIN departments ON employees.dept_id = departments.id เชื่อม 2 ตารางเข้าด้วยกันโดยจับคู่ Primary Key กับ Foreign Key
ORDER BY ORDER BY salary DESC เรียงลำดับผลลัพธ์ (ASC = น้อยไปมาก, DESC = มากไปน้อย)
