01

โครงสร้างโปรแกรมภาษา C# (Program Structure)

ทำความเข้าใจชิ้นส่วนสำคัญที่ประกอบกันขึ้นเป็นไฟล์โปรแกรม C#

💡 เปรียบเทียบให้เห็นภาพ (Analogy)
🏛️ อุปมาเปรียบเทียบสถาปัตยกรรมของโปรแกรม

ลองนึกถึงระบบบ้านและอาคาร:
• using (การขออนุญาตยืมเครื่องมือ) — เหมือนหยิบกล่องเครื่องมือมาตรฐานจากคลังมาใช้งาน
• namespace (ชื่อหมู่บ้าน/โครงการ) — ป้องกันไม่ให้ชื่อบ้านของแต่ละโครงการชนกัน
• class (ตัวบ้าน/ห้องทำงาน) — พิมพ์เขียวโครงสร้างที่รวมคำสั่งและข้อมูลไว้ด้วยกัน
• static void Main() (ประตูรั้วหน้าบ้าน) — ประตูบานแรกที่ระบบเปิดเข้ามาทำงานเสมอ (Entry Point)

📦 1. namespace MyFirstApp (ขอบเขตโครงการ)
🏠 2. class Program (คลาสหลัก)
🚪 3. static void Main(string[] args) (ประตูทางเข้าโปรแกรม)
⚡ 4. คำสั่งประมวลผล (Statements) เช่น Console.WriteLine(...)
📄 Program.cs 
// 1. นำเข้า Namespace พื้นฐานของ .NET
using System;

// 2. กำหนดขอบเขตชื่อโปรแกรม
namespace MyFirstApp
{
    // 3. ประกาศ Class สำหรับเก็บโค้ด
    class Program
    {
        // 4. Entry Point จุดเริ่มต้นที่โปรแกรมเริ่มรันเป็นจุดแรก
        static void Main(string[] args)
        {
            // คำสั่งพิมพ์ข้อความออกทางหน้าจอ Console
            Console.WriteLine("ยินดีต้อนรับสู่ DotNet Learning Hub! 🚀");
            Console.WriteLine("ภาษา C# เป็นภาษาแบบ Strongly-Typed ที่ทรงพลังและทำงานได้รวดเร็ว");

            // การอ่านข้อมูลอินพุต
            string learner = "Developer";
            Console.WriteLine($"สวัสดีคุณ {learner}! ขอให้สนุกกับการเขียนโค้ด");
        }
    }
}
▶ Output: ยินดีต้อนรับสู่ DotNet Learning Hub! 🚀 ภาษา C# เป็นภาษาแบบ Strongly-Typed ที่ทรงพลังและทำงานได้รวดเร็ว สวัสดีคุณ Developer! ขอให้สนุกกับการเขียนโค้ด
Keyword (using, namespace, class, static, void)
Type/Class (string, Program, Console)
Method (Main, WriteLine)
Parameter/Variable (args, learner)
String Literal ("ข้อความ")
💡 เกร็ดน่ารู้: Top-Level Statements ใน C# 9, 10, 11, 12

ในโปรเจกต์ .NET ยุคใหม่ คุณสามารถเขียนเพียงบรรทัดเดียว เช่น Console.WriteLine("Hello!"); ได้ทันทีโดยไม่ต้องครอบ namespace, class, หรือ Main() แต่เบื้องหลังคอมไพเลอร์ยังคงสร้างโครงสร้างเต็มรูปแบบให้อัตโนมัติ!

02

ตัวแปรและชนิดข้อมูล (Variables & Data Types)

การเก็บข้อมูลในหน่วยความจำด้วยชนิดข้อมูลที่ถูกต้องและปลอดภัย

📦 กล่องใส่ของ (Data Type Analogy)
🏷️ กล่องแต่ละใบรับสิ่งของคนละประเภท

ตัวแปรเปรียบเสมือน กล่องใส่ของที่ติดป้ายกำกับไว้:
• กล่อง int ออกแบบมาใส่ตัวเลขจำนวนเต็มเท่านั้น จะเอาน้ำหวาน (ข้อความ) มาเทใส่ไม่ได้
• ภาษา C# เป็นภาษา Strongly-Typed คอมไพเลอร์จะตรวจเช็กความถูกต้องของประเภทข้อมูลเสมอ ช่วยป้องกันข้อผิดพลาดตั้งแต่ตอนเขียนโค้ด

🔢 4 bytes (32-bit)
int
จำนวนเต็มบวก/ลบ (-2.14B ถึง +2.14B) เหมาะสำหรับนับจำนวน รอบลูป อายุ
int count = 42;
📝 2 bytes / char
string
ข้อความ ล้อมรอบด้วยเครื่องหมายคำพูดคู่ "" รองรับภาษาไทย UTF-16
string name = "สมชาย";
✅❌ 1 byte
bool
ค่าความจริง มีเพียง 2 สถานะคือ true (จริง) หรือ false (เท็จ)
bool isActive = true;
📊 8 bytes (64-bit)
double
เลขทศนิยมความละเอียด 15-17 ตำแหน่ง เหมาะกับการคำนวณทางวิทยาศาสตร์ พิกัด
double gpa = 3.85;
💰 16 bytes (128-bit)
decimal
ทศนิยมความละเอียดสูงมาก ต้องลงท้ายด้วย m หรือ M สำหรับงานการเงิน
decimal price = 1250.75m;
🔤 2 bytes
char
อักขระเดี่ยวตัวเดียว ล้อมรอบด้วยเครื่องหมายคำพูดเดี่ยว ''
char grade = 'A';
🎁 Type Inference
var
ให้คอมไพเลอร์คาดเดาชนิดข้อมูลอัตโนมัติจากค่าเริ่มต้น (ยังคงเป็น Strongly-Typed)
var lang = "C# 12";
📄 DataTypesDemo.cs 
using System;

class Program
{
    static void Main()
    {
        // การประกาศตัวแปรชนิดต่างๆ พร้อมกำหนดค่าเริ่มต้น
        string developerName = "กิตติพงษ์";
        int experienceYears = 3;
        double codeRating = 4.95;
        decimal hourlyRate = 1200.50m; // เติม 'm' ท้ายตัวเลข decimal เสมอ
        bool isAvailableForHire = true;
        char rankLevel = 'S';
        var favoriteFramework = ".NET 8 Web API"; // คอมไพเลอร์จะมองเป็น string ให้อัตโนมัติ

        // แสดงผลลัพธ์โดยใช้ String Interpolation ($"...")
        Console.WriteLine($"=== ข้อมูลนักพัฒนา: {developerName} (Rank: {rankLevel}) ===");
        Console.WriteLine($"ประสบการณ์: {experienceYears} ปี | คะแนนเฉลี่ย: {codeRating}/5.0");
        Console.WriteLine($"อัตราค่าจ้าง: {hourlyRate:N2} บาท/ชม. | พร้อมรับงาน: {isAvailableForHire}");
        Console.WriteLine($"เฟรมเวิร์กที่ถนัด: {favoriteFramework}");
    }
}
▶ Output: === ข้อมูลนักพัฒนา: กิตติพงษ์ (Rank: S) === ประสบการณ์: 3 ปี | คะแนนเฉลี่ย: 4.95/5.0 อัตราค่าจ้าง: 1,200.50 บาท/ชม. | พร้อมรับงาน: True เฟรมเวิร์กที่ถนัด: .NET 8 Web API
⚠️ กฎเหล็กเรื่องเงิน: ให้ใช้ decimal เสมอ!

ห้ามใช้ double หรือ float ในการคำนวณเงินหรือยอดบัญชี เพราะเลขทศนิยมฐานสอง (Binary Floating-point) มีโอกาสเกิดเศษทศนิยมคลาดเคลื่อน เช่น 0.1 + 0.2 = 0.30000000000000004 ในขณะที่ decimal ใช้เลขฐาน 10 จึงคำนวณเงินได้อย่างแม่นยำ 100%

03

เงื่อนไขและการตัดสินใจ (Control Flow: if, else, switch)

การกำหนดทิศทางการทำงานของโปรแกรมตามเงื่อนไขที่กำหนด

🚦 ป้ายบอกทางที่สี่แยก (Analogy)
🛣️ การเลือกเส้นทางเดินตามป้ายบอกทาง

คำสั่งเงื่อนไขเปรียบเหมือน ป้อมตรวจคนเข้าเมืองหรือทางแยก:
• ถ้าคุณถือบัตร VIP ให้เลี้ยวเข้าช่องด่วน (if)
• ถ้าไม่ใช่ แต่คุณมีตั๋วปกติ ให้เข้าช่องธรรมดา (else if)
• ถ้าไม่มีอะไรเลย ให้เข้าช่องติดต่อสอบถาม (else)

📄 IfElseDemo.cs 
using System;

class Program
{
    static void Main()
    {
        int age = 22;
        bool hasTicket = true;
        bool isVipMember = true;

        // โครงสร้าง if - else if - else
        if (!hasTicket)
        {
            Console.WriteLine("⛔ กรุณาซื้อบัตรผ่านประตูก่อนเข้าชม");
        }
        else if (age >= 18 && isVipMember)
        {
            Console.WriteLine("👑 ยินดีต้อนรับสู่ VIP Lounge (สิทธิ์สำหรับผู้ใหญ่)");
        }
        else if (age >= 18)
        {
            Console.WriteLine("🎫 ยินดีต้อนรับสู่โซนที่นั่งปกติ");
        }
        else
        {
            Console.WriteLine("🎈 ยินดีต้อนรับสู่โซนเยาวชนและครอบครัว");
        }

        // Ternary Operator (เงื่อนไขสั้น บรรทัดเดียว: เงื่อนไข ? จริง : เท็จ)
        string entryStatus = hasTicket ? "✅ อนุญาตให้เข้างาน" : "❌ ปฏิเสธการเข้า";
        Console.WriteLine($"สถานะ: {entryStatus}");
    }
}
▶ Output: 👑 ยินดีต้อนรับสู่ VIP Lounge (สิทธิ์สำหรับผู้ใหญ่) สถานะ: ✅ อนุญาตให้เข้างาน
📄 SwitchDemo.cs (Classic vs Modern Switch Expression) 
using System;

class Program
{
    static void Main()
    {
        string role = "Admin";

        // 1. Classic Switch Statement
        Console.WriteLine("--- Classic Switch ---");
        switch (role)
        {
            case "Admin":
                Console.WriteLine("🔑 สิทธิ์ Admin: สามารถจัดการระบบทั้งหมดได้");
                break;
            case "Editor":
                Console.WriteLine("✏️ สิทธิ์ Editor: สามารถสร้างและแก้ไขบทความได้");
                break;
            case "Viewer":
                Console.WriteLine("👁️ สิทธิ์ Viewer: สามารถอ่านเนื้อหาได้อย่างเดียว");
                break;
            default:
                Console.WriteLine("❓ ไม่พบสิทธิ์ที่ถูกต้องในระบบ");
                break;
        }

        // 2. Modern Switch Expression (C# 8+) — กะทัดรัด สวยงาม คืนค่าได้ทันที
        Console.WriteLine("\n--- Modern Switch Expression ---");
        int statusCode = 200;
        string message = statusCode switch
        {
            200 => "OK: คำขอสำเร็จบริบูรณ์ 🎉",
            201 => "Created: สร้างข้อมูลสำเร็จ",
            400 => "Bad Request: ข้อมูลส่งมาไม่ถูกต้อง",
            404 => "Not Found: ไม่พบหน้านี้ในเซิร์ฟเวอร์",
            500 => "Internal Server Error: เซิร์ฟเวอร์มีปัญหา",
            _   => "Unknown Status Code" // '_' คือ default
        };

        Console.WriteLine($"HTTP Status {statusCode}: {message}");
    }
}
▶ Output: --- Classic Switch --- 🔑 สิทธิ์ Admin: สามารถจัดการระบบทั้งหมดได้ --- Modern Switch Expression --- HTTP Status 200: OK: คำขอสำเร็จบริบูรณ์ 🎉
🎯 สรุปแนวทางเลือกใช้เงื่อนไข

• ใช้ if / else เมื่อเงื่อนไขเป็นช่วง เช่น score >= 80 หรือมีหลายตัวแปรร่วมกัน
• ใช้ switch / switch expression เมื่อต้องการเปรียบเทียบค่าคงที่ที่แน่นอนของตัวแปรเดี่ยว เช่น Role, Status Code, เมนูที่เลือก
• ใช้ Ternary ( ? : ) เมื่อต้องการกำหนดค่าให้ตัวแปรอย่างรวดเร็วแบบ 2 ทางเลือก

04

การวนซ้ำ (Loops: for, while, foreach)

การสั่งให้คอมพิวเตอร์ทำงานเดิมซ้ำๆ อย่างแม่นยำและมีประสิทธิภาพ

🏃‍♂️ การวิ่งรอบสนาม (Analogy)
🔄 รูปแบบการวิ่งวนแต่ละแบบ

• for loop — เหมือน "ครูสั่งให้วิ่ง 5 รอบสนาม" เรารู้จำนวนรอบที่แน่นอนก่อนออกวิ่ง
• while loop — เหมือน "วิ่งไปเรื่อยๆ ตราบใดที่พระอาทิตย์ยังไม่ตกดิน" ตรวจสอบเงื่อนไขก่อนวิ่งแต่ละรอบ
• foreach loop — เหมือน "วิ่งไปแวะทักทายเพื่อนทุกคนที่ยืนเรียงแถวอยู่ตามรายชื่อ" วนอ่านสมาชิกทุกคนในกลุ่มข้อมูลจนครบ

📄 LoopsDemo.cs 
using System;

class Program
{
    static void Main()
    {
        // 1. for loop: นับ 1 ถึง 5 (รู้จำนวนรอบแน่นอน)
        Console.WriteLine("--- 1. for loop (นับ 1-5) ---");
        for (int i = 1; i <= 5; i++)
        {
            Console.WriteLine($"🚩 วิ่งรอบที่ {i}");
        }

        // 2. while loop: ทำงานจนกว่าแบตเตอรี่จะหมด
        Console.WriteLine("\n--- 2. while loop ---");
        int battery = 3;
        while (battery > 0)
        {
            Console.WriteLine($"🔋 ใช้งานโดรน... พลังงานเหลือ: {battery} ขีด");
            battery--; // ลดค่าลงเพื่อไม่ให้เกิด Infinite Loop
        }
        Console.WriteLine("🪫 แบตเตอรี่หมดเกลี้ยง! กำลังลงจอดฉุกเฉิน");

        // 3. foreach loop: วนลูปอ่านค่าใน Array สะดวก ปลอดภัย ไม่ต้องกังวลเรื่อง Index
        Console.WriteLine("\n--- 3. foreach loop ---");
        string[] frameworks = { "ASP.NET Core", "Entity Framework", "Blazor", "MAUI" };
        
        foreach (string fw in frameworks)
        {
            Console.WriteLine($"⭐ เทคโนโลยี .NET: {fw}");
        }
    }
}
▶ Output: --- 1. for loop (นับ 1-5) --- 🚩 วิ่งรอบที่ 1 🚩 วิ่งรอบที่ 2 🚩 วิ่งรอบที่ 3 🚩 วิ่งรอบที่ 4 🚩 วิ่งรอบที่ 5 --- 2. while loop --- 🔋 ใช้งานโดรน... พลังงานเหลือ: 3 ขีด 🔋 ใช้งานโดรน... พลังงานเหลือ: 2 ขีด 🔋 ใช้งานโดรน... พลังงานเหลือ: 1 ขีด 🪫 แบตเตอรี่หมดเกลี้ยง! กำลังลงจอดฉุกเฉิน --- 3. foreach loop --- ⭐ เทคโนโลยี .NET: ASP.NET Core ⭐ เทคโนโลยี .NET: Entity Framework ⭐ เทคโนโลยี .NET: Blazor ⭐ เทคโนโลยี .NET: MAUI
⚠️ ระวัง Infinite Loop (ลูปไม่รู้จบ)!

เมื่อใช้ while หรือ do-while ต้องมั่นใจว่าภายในลูปมีการเปลี่ยนแปลงค่าตัวแปรเงื่อนไข (เช่น battery--) เสมอ มิฉะนั้นโปรแกรมจะทำงานวนซ้ำไม่หยุดจนทำให้ CPU ทำงาน 100% หรือโปรแกรมค้าง

05

เมธอดและฟังก์ชัน (Methods & Functions)

การจัดระเบียบโค้ดเป็นบล็อกย่อย เพื่อนำกลับมาใช้ซ้ำ (DRY: Don't Repeat Yourself)

⚙️ เครื่องจักรโรงงาน (Analogy)
🏭 วัตถุดิบ ➔ กระบวนการ ➔ ผลิตภัณฑ์

Method เปรียบเหมือน เครื่องจักรในโรงงาน:
• Parameters (พารามิเตอร์) = วัตถุดิบที่ป้อนเข้าเครื่อง
• Method Body ({...}) = กลไกการแปรรูปและคำนวณ
• Return Value (ค่าส่งกลับ) = สินค้าสำเร็จรูปที่ส่งออกมา
• หากเครื่องจักรมีหน้าที่เพียงทำความสะอาดแล้วจบ ไม่ต้องส่งสินค้าชิ้นใหม่ออกมา เราจะใช้ชนิดข้อมูล void

📄 MethodsDemo.cs 
using System;

class Program
{
    // 1. Void Method: ทำงานตามคำสั่ง ไม่คืนค่าใดๆ
    static void PrintBanner(string title)
    {
        Console.WriteLine("========================================");
        Console.WriteLine($"📌 {title}");
        Console.WriteLine("========================================");
    }

    // 2. Return Method: รับ Parameter และส่งผลลัพธ์ตัวเลขกลับไป
    static double CalculateDiscount(double originalPrice, double discountPercentage = 10.0)
    {
        double discountAmount = originalPrice * (discountPercentage / 100.0);
        double finalPrice = originalPrice - discountAmount;
        return finalPrice; // ส่งผลลัพธ์กลับ
    }

    // 3. Expression-Bodied Method: เขียนแบบย่อใน 1 บรรทัดด้วยแลมบ์ดา '=>' (C# 6+)
    static bool IsEven(int number) => number % 2 == 0;

    static void Main()
    {
        // เรียกใช้ Void Method
        PrintBanner("ระบบคำนวณโปรโมชันสินค้า");

        // เรียกใช้ Method คืนค่า
        double itemPrice = 2500.0;
        double salePrice = CalculateDiscount(itemPrice, 20.0);
        Console.WriteLine($"ราคาเดิม: {itemPrice:N2} บาท");
        Console.WriteLine($"ราคาหลังหักส่วนลด 20%: {salePrice:N2} บาท");

        // เรียกใช้ Expression-Bodied Method
        int testNumber = 42;
        Console.WriteLine($"เลข {testNumber} เป็นเลขคู่หรือไม่? ตอบ: {IsEven(testNumber)}");
    }
}
▶ Output: ======================================== 📌 ระบบคำนวณโปรโมชันสินค้า ======================================== ราคาเดิม: 2,500.00 บาท ราคาหลังหักส่วนลด 20%: 2,000.00 บาท เลข 42 เป็นเลขคู่หรือไม่? ตอบ: True
💡 ธรรมเนียมการตั้งชื่อ (Naming Convention) ใน C#

ในภาษา C# ชื่อของ Method, Class, Namespace, Property จะนิยมใช้รูปแบบ PascalCase (ขึ้นต้นด้วยตัวพิมพ์ใหญ่ทุกคำ) เช่น CalculateTotal(), GetUserById() ซึ่งต่างจากภาษา Java หรือ JavaScript ที่ใช้ camelCase

06

การจัดการข้อผิดพลาด (Error Handling: try / catch / finally)

ปกป้องแอปพลิเคชันจากการหยุดทำงานกะทันหันเมื่อเกิดเหตุการณ์ไม่คาดคิด

☂️ ร่มกันฝนและถุงลมนิรภัย (Analogy)
🛡️ การตั้งรับความผิดพลาดล่วงหน้า

• try (การออกไปข้างนอก) — ลองทำสิ่งที่อาจเกิดเหตุการณ์ไม่คาดคิด (เช่น ฝนตก หรือ ข้อมูลที่ผู้ใช้ป้อนผิด)
• catch (กางร่ม / ถุงลมนิรภัยทำงาน) — ดักจับเหตุการณ์และจัดการอย่างนุ่มนวล ไม่ให้โปรแกรมแครชพัง
• finally (กลับมาล้างเท้า / เก็บของ) — คำสั่งที่ ต้องทำเสมอ ไม่ว่าฝนจะตกหรือไม่ก็ตาม (เช่น ปิดไฟล์, ปิดการเชื่อมต่อฐานข้อมูล)

📄 TryCatchDemo.cs 
using System;

class Program
{
    static void Main()
    {
        string rawInput = "not-a-number"; // สมมติว่าผู้ใช้ป้อนข้อความแทนตัวเลข

        try
        {
            Console.WriteLine("1. เริ่มต้นบล็อก try: กำลังพยายามแปลงข้อมูล...");
            int parsedNumber = int.Parse(rawInput); // จะเกิด FormatException ทันที!
            
            // บรรทัดนี้จะไม่ถูกเรียกทำงานเพราะเกิด Exception ก่อนหน้า
            int calculation = 100 / parsedNumber;
            Console.WriteLine($"ผลลัพธ์: {calculation}");
        }
        catch (FormatException ex)
        {
            // ดักจับเฉพาะ Error ที่เกิดจากรูปแบบข้อความไม่ถูกต้อง
            Console.WriteLine($"⚠️ [FormatException]: ป้อนค่าไม่ใช่ตัวเลข! รายละเอียด: {ex.Message}");
        }
        catch (DivideByZeroException)
        {
            // ดักจับเฉพาะ Error การหารด้วยศูนย์
            Console.WriteLine("⚠️ [DivideByZeroException]: ตัวหารต้องไม่เป็นศูนย์ (0)");
        }
        catch (Exception ex)
        {
            // ดักจับ Exception ทั่วไปอื่นๆ ที่เหลือ
            Console.WriteLine($"❌ [General Exception]: เกิดข้อผิดพลาดไม่ทราบสาเหตุ: {ex.Message}");
        }
        finally
        {
            // ทำงานเสมอ 100% ไม่ว่าจะสำเร็จหรือเกิด Error
            Console.WriteLine("🔒 บล็อก finally: ปิดการเชื่อมต่อและคืนทรัพยากรเรียบร้อย");
        }

        Console.WriteLine("✅ โปรแกรมทำงานต่อได้ตามปกติ ไม่แครชดับกลางคัน!");
    }
}
▶ Output: 1. เริ่มต้นบล็อก try: กำลังพยายามแปลงข้อมูล... ⚠️ [FormatException]: ป้อนค่าไม่ใช่ตัวเลข! รายละเอียด: The input string 'not-a-number' was not in a correct format. 🔒 บล็อก finally: ปิดการเชื่อมต่อและคืนทรัพยากรเรียบร้อย ✅ โปรแกรมทำงานต่อได้ตามปกติ ไม่แครชดับกลางคัน!
💡 Pro Tip: การใช้ int.TryParse()

หากต้องการแปลงสตริงเป็นตัวเลข การใช้ int.TryParse(input, out int result) จะให้ประสิทธิภาพสูงกว่าการใช้ try-catch มาก เพราะไม่ต้องสร้าง Exception Object ในหน่วยความจำเมื่อแปลงไม่สำเร็จ!
