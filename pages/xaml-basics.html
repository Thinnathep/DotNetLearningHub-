XAML พื้นฐานสำหรับ .NET MAUI & WPF

ภาษา Declarative Markup บนโครงสร้าง XML สำหรับออกแบบ User Interface บน Cross-Platform Desktop/Mobile, Layout Panels, Data Binding และสถาปัตยกรรม MVVM

⭐ ระดับ: พื้นฐาน > กลาง ⏱️ เวลา: ~45 นาที ⚡ รางวัล: +100 XP 🏷️ .NET MAUI / WPF / MVVM
🏠 เปรียบเทียบให้เห็นภาพ: พิมพ์เขียวบ้านและระบบสายไฟในผนัง
💡 Analogy

• XAML File (.xaml): เหมือน ผนังห้องและตำแหน่งเฟอร์นิเจอร์ (View) ที่บอกว่าสวิตช์ไฟ หลอดไฟ อยู่ตรงไหน
• Data Binding: เหมือน สายไฟที่ร้อยอยู่ในผนัง เชื่อมปุ่มกดบนผนังเข้ากับกล่องควบคุมในห้องเครื่อง
• ViewModel (.cs): เหมือน กล่องควบคุมไฟฟ้า (Logic) ที่รับคำสั่งเปิด-ปิดไฟ คำนวณค่าไฟ โดยไม่ต้องสนใจว่าหลอดไฟที่ติดอยู่บนผนังเป็นโคมแบบไหน (UI-independent)

01

โครงสร้างพื้นฐานของไฟล์ XAML

XAML (Extensible Application Markup Language) ใช้แท็ก XML ในการประกาศ Elements และ Properties ของหน้าจอ:

📄 MainPage.xaml (.NET MAUI)
<?xml version="1.0" encoding="utf-8" ?>
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             xmlns:viewmodels="clr-namespace:MyApp.ViewModels"
             x:Class="MyApp.MainPage"
             Title="หน้าหลัก">

    <VerticalStackLayout Spacing="20" Padding="30">
        <Label Text="ยินดีต้อนรับสู่ .NET MAUI!"
               FontSize="24"
               HorizontalOptions="Center"
               TextColor="#58A6FF" />

        <Entry Text="{Binding Username, Mode=TwoWay}"
               Placeholder="กรุณากรอกชื่อของคุณ" />

        <Button Text="เข้าสู่ระบบ"
                Command="{Binding LoginCommand}"
                BackgroundColor="#3FB950"
                TextColor="White" />
    </VerticalStackLayout>

</ContentPage>
02

Layout Containers สำคัญใน XAML

📑 StackLayout

จัดเรียงองค์ประกอบต่อกันในทิศทางเดียว (แนวตั้ง VerticalStackLayout หรือแนวนอน HorizontalStackLayout)

📊 Grid Layout

จัดวางแบบตารางแถวและคอลัมน์ (RowDefinitions, ColumnDefinitions) รองรับขนาด * (Proportional) และ Auto

🔲 FlexLayout

จัดเรียงคล้าย CSS Flexbox รองรับการขึ้นบรรทัดใหม่อัตโนมัติ (Wrap) เหมาะสำหรับ Responsive UI

03

สถาปัตยกรรม MVVM (Model - View - ViewModel)

MVVM คือหัวใจหลักของการพัฒนาแอปด้วย XAML เพื่อแยก UI ออกจาก Business Logic:

📄 MainViewModel.cs (CommunityToolkit.Mvvm)
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;

public partial class MainViewModel : ObservableObject
{
    // สร้าง Property พร้อมระบบแจ้งเตือน UI อัตโนมัติ (INotifyPropertyChanged)
    [ObservableProperty]
    private string _username = string.Empty;

    [ObservableProperty]
    private bool _isLoading;

    // สร้าง Command แทน Event Handler เดิม
    [RelayCommand]
    private async Task LoginAsync()
    {
        if (string.IsNullOrWhiteSpace(Username)) return;

        IsLoading = true;
        await Task.Delay(1000); // จำลองการเรียก API
        IsLoading = false;
    }
}
