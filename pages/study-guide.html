คู่มือการเรียน & แผนที่เตรียมสอบสัมภาษณ์ Junior .NET Developer

แนะนำลำดับการเรียนรู้ 3 สเต็ปที่ตรงจุดที่สุด, วิธีทบทวนเนื้อหาโดยไม่เสียเวลา, เทคนิคการทำคะแนนในห้องสัมภาษณ์ และการใช้งานแพลตฟอร์มอย่างเต็มประสิทธิภาพ

🐱 คำแนะนำจากพี่สาว .NET Architect: "เรียนอย่างไรไม่ให้หลงทาง?"

"ในแพลตฟอร์มนี้มีเนื้อหาครบ 10 Tracks 28 หน้าเว็บ แต่สำหรับน้องที่กำลังเตรียมสมัครงาน Junior Backend .NET Developer น้องไม่จำเป็นต้องอ่านทุกหน้าพร้อมกันในวันเดียวค่ะ! ให้โฟกัสที่ Core 80% ที่กรรมการสัมภาษณ์ถามบ่อยที่สุดก่อน แล้วค่อยขยายไปยังส่วนเสริม พี่สาวจัดตารางเรียน 3 สัปดาห์ไว้ให้ด้านล่างนี้แล้ว เดินตามนี้ได้เลยจ้า!"

🗺️ แผนที่การเรียน 3 สัปดาห์ (3-Week Step-by-Step Plan)

1
สัปดาห์ที่ 1: C# & Core Engine
ปูพื้นฐาน & OOP & DI
  • 📗 Day 1: C# พื้นฐาน (ตัวแปร/ลูป/Try-Catch)
  • 📘 Day 2: C# OOP (Interface/Polymorphism)
  • 📕 Day 3: C# ขั้นสูง (Async/Await & Task) ⚠️
  • 🏗️ Day 4: โครงสร้าง ASP.NET Core & Program.cs
  • 💉 Day 5: Dependency Injection (3 Lifetimes) ⚠️
🎯 เป้าหมาย: อธิบายได้ว่า DI 3 Lifetimes ต่างกันอย่างไร และทำไมห้ามใช้ `.Result`
2
สัปดาห์ที่ 2: APIs & Database
Web API & EF Core & Testing
  • 🔌 Day 6: RESTful API Design & Status Codes
  • 📊 Day 7: SQL Basics & JOINs + Sandbox
  • 🗄️ Day 8: EF Core (DbContext & N+1 Query) ⚠️
  • ✅ Day 9: Unit Testing (xUnit & Moq AAA)
  • 🛡️ Day 10: Secure Coding (OWASP & DB-First)
🎯 เป้าหมาย: สร้าง Web API เชื่อม Database ด้วย EF Core และเขียน Unit Test ดักจับบัคได้
3
สัปดาห์ที่ 3: สถาปัตยกรรม & ซ้อมสัมภาษณ์
Clean Arch & Mock Interview
  • 🏛️ Day 11: Clean Architecture 4 เลเยอร์ & CQRS
  • 💼 Day 12: ซ้อมตอบคำถามสัมภาษณ์ (STAR Method) ⚠️
  • 🎯 Day 13: ตะลุยด่าน Quiz Arena ทุกหมวด
  • 📖 Day 14: ทบทวนคำศัพท์ภาษาอังกฤษ & คำอ่าน
  • 💻 Day 15: ทดลองเขียนโค้ดสดใน Sandbox
🎯 เป้าหมาย: พูดตอบคำถามสัมภาษณ์ได้อย่างมั่นใจ มีหลักการ และยกตัวอย่างจริงได้

✅ Checklist เตรียมความพร้อมก่อนวันสัมภาษณ์งาน

🧠 คำถามเชิงเทคนิค (Technical Must-Know)

  • [ ] อธิบายความต่างของ AddTransient, AddScoped, AddSingleton ได้
  • [ ] รู้จักกับดัก Captive Dependency และวิธีแก้ด้วย IServiceScopeFactory
  • [ ] อธิบายการทำงานของ async / await (Non-blocking I/O vs Thread Blocking)
  • [ ] อธิบายปัญหา N+1 Query ใน EF Core และวิธีแก้ด้วย .Include()
  • [ ] ทราบเหตุผลที่ต้องใช้ .AsNoTracking() ใน Read queries
  • [ ] อธิบายความต่างของ HTTP Status Codes: 200, 201, 204, 400, 401, 403, 404, 500
  • [ ] เขียน Unit Test รูปแบบ AAA Pattern (Arrange-Act-Assert) ร่วมกับ Moq ได้

🌟 พฤติกรรมและการสื่อสาร (Behavioral & STAR Method)

  • [ ] เตรียมการแนะนำตัวสั้นๆ 1-2 นาที เน้นความหลงใหลใน .NET Core Backend
  • [ ] มีเรื่องเล่าแก้ปัญหาบัคยากๆ 1 เรื่องโดยใช้โครงสร้าง **STAR (Situation, Task, Action, Result)**
  • [ ] มีทัศนคติเชิงบวกต่อการทำ **Code Review** และการทำงานเป็นทีม (Agile/Scrum)
  • [ ] เตรียมคำถามฉลาดๆ ถามกลับกรรมการ 2-3 ข้อ (เช่น "ทีมใช้ .NET 8 หรือ 9?", "กระบวนการ CI/CD ในทีมเป็นอย่างไร?")
  • [ ] มั่นใจในการออกเสียงศัพท์เทคนิคภาษาอังกฤษ (เปิดดูที่ Tech Glossary)
