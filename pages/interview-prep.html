คลังคำถาม & จำลองสัมภาษณ์งาน Junior .NET Developer

รวมคำถามสัมภาษณ์งานจริงทั้ง Technical และ Behavioral, เทคนิคการตอบด้วยเทคนิค STAR Method และระบบจำลองสัมภาษณ์เสมือนจริงเพื่อคว้างานแรกของคุณ!

⭐ เทคนิคการตอบคำถามสัมภาษณ์ด้วย STAR Method

S - Situation (สถานการณ์)

เล่าบริบทและสภาพแวดล้อมของโปรเจกต์สั้นๆ

T - Task (โจทย์/เป้าหมาย)

อธิบายปัญหาที่ต้องแก้ หรือฟีเจอร์ที่ได้รับมอบหมาย

A - Action (การลงมือทำ)

อธิบายสิ่งที่เรา ลงมือทำด้วยตนเอง เช่น เลือกใช้ DI, Optimize SQL, ออกแบบ DTO

R - Result (ผลลัพธ์ที่วัดได้)

สรุปผลลัพธ์ที่เป็นตัวเลข เช่น "API ตอบสนองเร็วขึ้น 40%, รัน Unit Test ผ่าน 100%"

🎯 10 คำถามสัมภาษณ์ทางเทคนิคยอดฮิต พร้อมแนวทางตอบระดับ Senior

แนวทางการตอบ:
• Transient: สร้าง Instance ใหม่ทุกครั้งที่มีการร้องขอ เหมาะสำหรับ Stateless helper service
• Scoped: สร้าง 1 Instance ต่อ 1 HTTP Request และแชร์ร่วมกันใน Request นั้น เหมาะสำหรับ DbContext และ Business Services
• Singleton: สร้างเพียงครั้งเดียวตลอดอายุแอปพลิเคชัน เหมาะสำหรับ In-Memory Cache หรือ Logger
⚠️ จุดเพิ่มคะแนน: พูดถึงความเสี่ยงของ Captive Dependency ว่าห้ามฉีด Scoped เข้า Singleton เด็ดขาด

แนวทางการตอบ:
• async/await ใน C# เป็นกลไกแบบ Non-blocking I/O ที่คืน Thread กลับสู่ Thread Pool ระหว่างรอการตอบกลับจาก Database หรือ Network โดยไม่สร้าง Thread ใหม่ขึ้นมาให้สิ้นเปลือง
• ช่วยให้ Web Server รองรับ Concurrent Requests ได้จำนวนมหาศาลโดยไม่เกิด Thread Starvation
⚠️ จุดเพิ่มคะแนน: เน้นย้ำว่าห้ามใช้ .Result หรือ .Wait() เพราะจะบล็อก Thread และเสี่ยงเกิด Deadlock

แนวทางการตอบ:
• เกิดจากการดึงข้อมูลหลัก 1 Query แล้ววนลูปส่ง Query ย่อยไปดึงข้อมูลลูกอีก N ครั้ง (รวมเป็น 1 + N Queries) ทำให้ Database โดนยิงรัวจนช้า
• วิธีแก้: ใช้ Eager Loading ด้วยคำสั่ง .Include(x => x.OrderItems) หรือใช้ DTO Projection ด้วย .Select() เพื่อรวมเป็น SQL JOIN ตัวเดียว

แนวทางการตอบ:
• เมื่อเรียก Query ข้อมูลแบบ Read-Only การใส่ .AsNoTracking() จะบอกให้ EF Core ปิดระบบ Change Tracker ไม่ต้องจดจำสถานะของ Entity ใน Memory
• ส่งผลให้ประหยัด RAM มหาศาลและ Query เร็วขึ้นกว่าเดิมอย่างเห็นได้ชัด

แนวทางการตอบ:
• UI เป็นเพียง Client-side ซึ่งผู้ไม่หวังดีสามารถใช้ DevTools หรือยิงคำขอตรงผ่าน Postman/cURL เข้าหา API ได้เสมอ (Client-side Bypass)
• มาตรการที่ถูกต้อง: ต้องใช้หลักการ Database-First Security & API Authorization โดยตรวจสอบสิทธิ์ด้วย [Authorize] และตรวจสอบความเป็นเจ้าของข้อมูลที่ระดับ Database Row-Level Security เสมอ
