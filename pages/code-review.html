Code Review, Clean Code & SOLID Principles

มาตรฐานการรีวิวโค้ดในทีมระดับมืออาชีพ, 5 เสาหลัก SOLID Principles ในภาษา C#, Clean Code Guidelines และการสร้างวัฒนธรรม Constructive Feedback

⭐ ระดับ: กลาง ⏱️ เวลา: ~45 นาที ⚡ รางวัล: +100 XP 🏷️ SOLID / Clean Code / PR Checklist
👥 เปรียบเทียบให้เห็นภาพ: การตรวจทานบทความวิชาการ (Peer Review)
💡 Analogy

• Code Review: ไม่ใช่ "การจับผิดเพื่อตำหนิ" แต่เหมือน นักบินผู้ช่วย (Co-Pilot) ที่ช่วยตรวจเช็ค Checklists ก่อนเครื่องขึ้น เพื่อความปลอดภัยของผู้โดยสารทุกคน
• SOLID Principles: เหมือน มาตรฐานโครงสร้างตึกระฟ้า ที่ออกแบบให้แต่ละห้องซ่อมแซม ต่อเติมระบบไฟฟ้า โดยไม่ต้องทุบเสาหลักของตึกทิ้ง

01

5 เสาหลัก SOLID Principles ในภาษา C#

🎯 S - Single Responsibility (SRP)

1 คลาสควรมี หน้าที่รับผิดชอบเพียงอย่างเดียว (1 เหตุผลในการแก้ไข)
❌ UserService ที่ทั้งสร้าง User, ส่งอีเมล, และเขียน Log ลง Text file
✅ แยกเป็น UserService, EmailService, AppLogger

🔓 O - Open/Closed (OCP)

เปิดรับการขยาย (Open for extension) แต่ ปิดการแก้ไขโค้ดเดิม (Closed for modification)
✅ ใช้ Interface หรือ Strategy Pattern เพิ่มวิธีคิดส่วนลดใหม่ๆ โดยไม่ต้องแก้ switch/case เดิม

🔄 L - Liskov Substitution (LSP)

คลาสลูก (Subclass) ต้องสามารถ ใช้แทนคลาสแม่ (Base Class) ได้อย่างสมบูรณ์ โดยไม่ทำให้โปรแกรมทำงานผิดพลาดหรือโยน Unexpected Exception

✂️ I - Interface Segregation (ISP)

แยก Interface ให้เล็กและเฉพาะทาง ดีกว่า Interface ขนาดใหญ่ที่บังคับให้ Class ต้อง Implement เมธอดที่ตัวเองไม่ได้ใช้งาน (เช่น แยก IReadable และ IWritable)

💉 D - Dependency Inversion Principle (DIP)

Module ระดับสูงและระดับต่ำ ต้องขึ้นต่อ Abstraction (Interface) ไม่ใช่ขึ้นต่อ Concrete Class ตรงๆ (หัวใจหลักของ Dependency Injection)

02

Pull Request (PR) Review Checklist สำหรับ Junior .NET

มิติการตรวจเช็ค คำถามสำคัญในการรีวิวโค้ด เกณฑ์ผ่าน (Pass Criteria)
🛡️ Security มี Hardcoded Secrets, SQL Injection หรือ IDOR หรือไม่? ไม่มีรหัสผ่านใน Git, ใช้ Parameterized Query, มี `[Authorize]`
⚡ Performance มีปัญหา N+1 Query หรือบล็อก Thread ด้วย `.Result` หรือไม่? ใช้ `AsNoTracking()`, Eager Loading `.Include()`, Async/Await ตลอดสาย
🧪 Testability มี Unit Test ครอบคลุม Logic ใหม่และกรณี Edge Cases หรือไม่? xUnit Test รันผ่าน 100% ใน CI Pipeline
📖 Readability ตั้งชื่อตัวแปรสื่อความหมาย (No Magic Numbers/Strings) หรือไม่? อ่านโค้ดเข้าใจได้โดยไม่ต้องมี Comment อธิบายยาว
