01

แนวคิด 3 เสาหลักของการสร้างเว็บ (The 3-Layer Cake Analogy)

ทำความเข้าใจหน้าที่และบทบาทของ HTML, CSS และ JavaScript ผ่านการเปรียบเทียบในชีวิตจริง

💡 เปรียบเทียบให้เห็นภาพ (Analogy: การสร้างบ้าน 1 หลัง)
🏠 บ้าน 1 หลังต้องมีโครงสร้าง ความสวยงาม และระบบไฟฟ้าที่ใช้งานได้จริง

หากเปรียบเทียบหน้าเว็บไซต์ (Web Page) กับการสร้างบ้านหรือร่างกายมนุษย์:
• HTML (Structure / กระดูก & โครงสร้างบ้าน) — กำหนดเสา คาน อิฐ ผนัง ประตู และหน้าต่าง ว่ามีอะไรอยู่ตรงไหนบ้าง ให้ความหมายและความสมบูรณ์ของเนื้อหา
• CSS (Presentation / ผิวหนัง เสื้อผ้า & สีทาบ้าน) — กำหนดสีสัน ขนาด ลวดลาย สไตล์ การจัดวางตำแหน่ง (Layout) และความสวยงามน่าใช้งาน
• JavaScript (Behavior / สมอง กล้ามเนื้อ & ระบบไฟฟ้าประปา) — ทำให้เกิดการเคลื่อนไหว เมื่อกดสวิตช์ไฟจะติด เมื่อเปิดก๊อกน้ำจะไหล สามารถคำนวณและตอบสนองต่อผู้ใช้งานได้แบบ Real-time

</>
1. HTML (HyperText Markup Language) Structure
สร้างโครงสร้าง ความหมายของเนื้อหา (Content & Semantics) เช่น หัวข้อ ย่อหน้า รูปภาพ ฟอร์ม และตาราง
🧱 เปรียบเสมือน: โครงสร้างคอนกรีต อิฐ เสาเข็ม และกำแพงบ้าน
🎨
2. CSS (Cascading Style Sheets) Presentation
กำหนดการแสดงผล ความสวยงาม ฟอนต์ สีสัน ระยะห่าง แอนิเมชัน และการจัดหน้าจอ Responsive ทุกขนาด
🛋️ เปรียบเสมือน: สีทาบ้าน วอลเปเปอร์ เฟอร์นิเจอร์ตกแต่ง และแสงไฟสร้างบรรยากาศ
⚡
3. JavaScript (Programming Language) Behavior
เพิ่มตรรกะ การโต้ตอบ (Interactivity) การดึงข้อมูลจาก API หลังบ้าน การตรวจสอบข้อมูลฟอร์ม และอัปเดตหน้าจอโดยไม่ต้องรีเฟรช
💡 เปรียบเสมือน: สวิตช์ไฟ ประตูอัตโนมัติ ท่อประปา และระบบ Smart Home
ภาษา / เทคโนโลยี หน้าที่หลัก (Core Responsibility) นามสกุลไฟล์ ตัวอย่างโค้ดสั้น บทบาทใน .NET / Full-Stack
HTML5 โครงสร้าง & ความหมายของข้อมูล .html / .cshtml / .razor <button class="btn">สั่งซื้อ</button> Razor Pages / Blazor Render Tree
CSS3 ความสวยงาม Layout & Responsive .css / .scss .btn { background: #58a6ff; } CSS Isolation ใน Blazor / UI Libraries

02

HTML โครงสร้างและ Semantics (HTML Structure & Semantic Tags)

สร้างโครงสร้างเว็บที่ถูกต้องตามหลักมาตรฐาน เข้าถึงง่าย (Accessibility) และเป็นมิตรกับ Search Engine (SEO)

🧱 โครงกระดูกพื้นฐานของไฟล์ HTML (HTML Document Skeleton)

ทุกไฟล์ HTML จะต้องเริ่มต้นด้วย <!DOCTYPE html> เพื่อบอก Browser ว่านี่คือเอกสาร HTML5 และประกอบด้วย 2 ส่วนหลักคือ <head> (ข้อมูลการตั้งค่า Meta) และ <body> (ส่วนเนื้อหาที่แสดงผลบนหน้าจอ)

📄 index.html 
<!DOCTYPE html>
<html lang="th">
<head>
  <!-- ข้อมูล Meta และการตั้งค่าหน้าเว็บ -->
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>ร้านค้าออนไลน์ .NET Store</title>
  <!-- เชื่อมโยงไฟล์ CSS ภายนอก -->
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- ส่วนเนื้อหาทั้งหมดที่มองเห็นได้บนหน้าจอ -->
  <h1>ยินดีต้อนรับสู่ .NET Store</h1>
  <p>แหล่งรวมสินค้าไอทีและคอร์สเรียนการเขียนโปรแกรม</p>

  <!-- เชื่อมโยงไฟล์ JavaScript -->
  <script src="app.js"></script>
</body>
</html>
HTML Tag (<html>, <head>, <body>)
Attribute (lang, charset, name, content, href, src)
Attribute Value ("th", "UTF-8", "styles.css")
Comment (<!-- คำอธิบาย -->)
🏷️ Semantic HTML5 Tags (แท็กที่บ่งบอกความหมายชัดเจน)

ในอดีต นักพัฒนามักใช้ <div> ครอบทุกอย่าง แต่ใน HTML5 ได้เพิ่ม Semantic Tags เพื่อให้เบราว์เซอร์, โปรแกรมอ่านหน้าจอสำหรับผู้พิการ (Screen Readers) และ Google Bot เข้าใจโครงสร้างของหน้าเว็บได้อย่างแม่นยำ

🔝 <header> — ส่วนหัวของหน้าเว็บ / โลโก้ / แบนเนอร์หลัก
🧭 <nav> — แถบเมนูนำทาง (Navigation Bar / Links)
🎯 <main> — เนื้อหาหลักของหน้านี้ (มีได้เพียง 1 อันต่อหน้า)
📰 <article> — บทความ / โพสต์ / การ์ดสินค้า ที่แยกอ่านเดี่ยวๆ ได้
📑 <section> — ส่วนย่อยแบ่งตามหัวข้อเรื่อง
📌 <aside>
Sidebar / แถบข้าง / ลิงก์ที่เกี่ยวข้อง / โฆษณา
🔻 <footer> — ส่วนท้ายของหน้าเว็บ / ลิขสิทธิ์ / ข้อมูลติดต่อ / ลิงก์นโยบาย
<h1> ถึง <h6> Headings
หัวข้อระดับ 1 ถึง 6 โดย <h1> มีความสำคัญสูงสุด ควรมีเพียง 1 จุดต่อหน้าเพื่อผลดีต่อ SEO
<h1>หัวข้อหลักของบทความ</h1>
<p>, <strong>, <em> Text Formatting
<p> สำหรับย่อหน้าข้อความ, <strong> เน้นความสำคัญ (ตัวหนา), <em> เน้นเสียงคำ (ตัวเอียง)
<p>เรียนรู้ <strong>.NET 8</strong> ได้แล้ววันนี้</p>
<a> & <img> Links & Media
<a href="..."> สร้างลิงก์ และ <img src="..." alt="..."> แสดงรูปภาพ (ต้องมี alt เสมอ)
<a href="/profile">ดูโปรไฟล์</a>
<ul>, <ol>, <li> Lists
<ul> รายการแบบไม่มีลำดับ (Bullet points), <ol> รายการแบบมีตัวเลขลำดับ, และ <li> คือสมาชิกแต่ละข้อ
<ul><li>HTML5</li><li>CSS3</li></ul>
📋 Forms & Input Controls (การรับส่งข้อมูลผ่านฟอร์ม)

ฟอร์มคือหัวใจหลักในการรับข้อมูลจากผู้ใช้เพื่อส่งไปยัง Backend API (เช่น ASP.NET Core Controller) การผูก <label for="id"> กับ <input id="id" name="key"> มีความสำคัญอย่างยิ่งในการจับคู่ข้อมูล

📄 register-form.html 
<!-- ฟอร์มสำหรับส่งข้อมูลไปยัง ASP.NET Core API -->
<form action="/api/users/register" method="POST" id="registerForm">
  <!-- ช่องกรอกข้อความทั่วไป -->
  <div class="form-group">
    <label for="username">ชื่อผู้ใช้ (Username):</label>
    <input type="text" id="username" name="username" placeholder="เช่น somchai_dev" required>
  </div>

  <!-- ช่องกรอกอีเมล (ตรวจเช็ก format อัตโนมัติ) -->
  <div class="form-group">
    <label for="email">อีเมล:</label>
    <input type="email" id="email" name="email" placeholder="user@example.com" required>
  </div>

  <!-- ช่องกรอกรหัสผ่าน (ซ่อนตัวอักษร) -->
  <div class="form-group">
    <label for="password">รหัสผ่าน:</label>
    <input type="password" id="password" name="password" minlength="8" required>
  </div>

  <!-- เมนูดรอปดาวน์ (Select & Option) -->
  <div class="form-group">
    <label for="role">ตำแหน่งที่สนใจ:</label>
    <select id="role" name="role">
      <option value="backend">C# / .NET Backend Developer</option>
      <option value="fullstack">Full-Stack Blazor Developer</option>
      <option value="frontend">Frontend Developer</option>
    </select>
  </div>

  <!-- กล่องข้อความหลายบรรทัด -->
  <div class="form-group">
    <label for="bio">แนะนำตัวสั้นๆ:</label>
    <textarea id="bio" name="bio" rows="3"></textarea>
  </div>

  <!-- ปุ่มกดยืนยัน -->
  <button type="submit" class="btn btn-primary">🚀 สมัครสมาชิก</button>
</form>

CSS พื้นฐานและการจัด Layout (CSS Selectors, Box Model & Flexbox)

ควบคุมหน้าตา สีสัน สัดส่วน การจัดวาง Flexbox และ Responsive Design ให้รองรับทุกหน้าจอ

🎯 ตัวเลือก CSS (CSS Selectors & Specificity)

CSS Selector คือวิธีการระบุเป้าหมายว่าต้องการให้โค้ดสไตล์ไปปรับแต่ง Element ตัวใดในหน้า HTML

ประเภท Selector ไวยากรณ์ (Syntax) เป้าหมายที่เลือก ตัวอย่างการใช้งานจริง
Element Selector tag { ... } เลือกทุกแท็กของชื่อนั้น p { line-height: 1.6; } (เปลี่ยนทุกย่อหน้า)
Class Selector .className { ... } เลือกทุก Element ที่มี class ตรงกัน (ใช้ซ้ำได้หลายที่) .btn-primary { background: #58a6ff; }
ID Selector #idName { ... } เลือก Element ที่มี ID เฉพาะเจาะจง (ควรมีเพียง 1 ตัวต่อหน้า) #navbar { position: fixed; }
Pseudo-class selector:hover เลือกตามสถานะของผู้ใช้ (เช่น นำเมาส์ไปชี้, โฟกัส) .card:hover { transform: translateY(-3px); }
Descendant / Child .parent .child / parent > child เลือก Element ลูกหลานที่อยู่ภายในกล่องแม่ .nav-list > li { display: inline-block; }
📦 โมเดลกล่องของ CSS (The CSS Box Model)
🖼️ เปรียบเสมือนรูปภาพที่ใส่กรอบแขวนบนฝาผนัง

ทุก Element บนหน้าเว็บ HTML คือกล่องสี่เหลี่ยมที่ประกอบด้วย 4 เลเยอร์จากนอกเข้าใน:
• Margin (ระยะห่างภายนอก) — ระยะเว้นว่างระหว่างกล่องนี้กับกล่องเพื่อนบ้านรอบๆ (โปร่งใส)
• Border (เส้นขอบ) — เส้นกรอบรูปที่มีความหนา สี และรูปแบบเส้น
• Padding (ระยะเว้นว่างภายใน) — ระยะช่องไฟระหว่างเส้นขอบรูปกับตัวเนื้อหารูปภาพ
• Content (เนื้อหา) — ตัวเนื้อหา ตัวอักษร หรือรูปภาพด้านในสุด

MARGIN (ระยะห่างภายนอกขอบ)
BORDER (เส้นขอบความหนา)
PADDING (ระยะเว้นวรรคภายใน)
CONTENT (ข้อความ / รูปภาพ / วิดีโอ กว้าง x สูง)
💡 กฎทองของ Web Developer: `box-sizing: border-box`

โดยค่าเริ่มต้นของเบราว์เซอร์ เมื่อเราเพิ่ม padding หรือ border ขนาดความกว้างรวมของกล่องจะขยายใหญ่ขึ้น ทำให้ layout พังง่าย! ดังนั้นโปรเจกต์เว็บยุคใหม่จึงมักใส่โค้ด Reset เสมอ:
*, *::before, *::after { box-sizing: border-box; } เพื่อให้ความกว้าง (Width) รวม Padding และ Border ให้อัตโนมัติ

📐 การจัดเลย์เอาต์ด้วย CSS Flexbox (1-Dimensional Layout)

Flexbox เป็นเครื่องมือมาตรฐานในการจัดเรียง Element ลูกให้อยู่ในแถวแนวนอนหรือแนวตั้ง จัดตำแหน่งกึ่งกลาง และกระจายระยะห่างอย่างยืดหยุ่น

🎨 layout.css 
/* กล่องแม่ (Flex Container) */
.navbar-container {
  display: flex;                /* เปิดใช้งาน Flexbox */
  flex-direction: row;          /* จัดเรียงแนวนอน (ค่าเริ่มต้น) */
  justify-content: space-between; /* กระจายเนื้อหาชิดซ้ายและขวาสุด */
  align-items: center;          /* จัดกึ่งกลางในแนวตั้ง */
  gap: 1.5rem;                  /* ระยะห่างระหว่างกล่องลูก */
  padding: 1rem 2rem;
  background-color: #161b22;
}

/* จัดกึ่งกลางแบบสมบูรณ์แบบ (Center Anything) */
.hero-center-box {
  display: flex;
  justify-content: center; /* กึ่งกลางแนวนอน */
  align-items: center;     /* กึ่งกลางแนวตั้ง */
  min-height: 300px;
}
📱 การทำเว็บรองรับทุกหน้าจอด้วย @media Queries (Responsive Design)

ใช้ @media เพื่อปรับสไตล์ตามขนาดความกว้างหน้าจอ เช่น บนมือถือเปลี่ยน Flex แถวแนวนอนเป็นแนวตั้ง:

🎨 responsive.css 
/* สไตล์สำหรับ Desktop (หน้าจอกว้าง) */
.product-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 คอลัมน์ */
  gap: 20px;
}

/* เมื่อหน้าจอเล็กกว่าหรือเท่ากับ 768px (Tablet & Mobile) */
@media (max-width: 768px) {
  .product-grid {
    grid-template-columns: 1fr; /* ปรับเหลือ 1 คอลัมน์เต็มหน้าจอ */
  }

  .navbar-container {
    flex-direction: column; /* เรียงเมนูจากบนลงล่าง */
    align-items: flex-start;
  }
}

JavaScript พื้นฐานและการจัดการ DOM (JavaScript & DOM Manipulation)

ตัวแปร ฟังก์ชัน การดักจับ Event การแก้ไข DOM แบบ Real-time และการเรียก Backend Web API ด้วย Fetch & Async/Await

⚡ ตัวแปรและฟังก์ชันใน Modern JavaScript (ES6+)
🔒 เลือกประเภทตัวแปรให้เหมาะสมกับงาน

• const — ตัวแปรค่าคงที่ (Constant) ไม่สามารถเปลี่ยนค่าใหม่ได้ ป้องกันบั๊กได้ดีที่สุด (แนะนำให้ใช้เป็นค่าเริ่มต้นเสมอ)
• let — ตัวแปรที่เปลี่ยนค่าได้ มีขอบเขตทำงานเฉพาะใน Block { ... } ที่ประกาศ
• var — ตัวแปรแบบเก่า มีปัญหาเรื่อง Hoisting และ Scope รั่วไหล (ไม่แนะนำให้ใช้ในโค้ดยุคใหม่)

📜 basics.js 
// 1. การประกาศตัวแปร
const apiBaseUrl = "https://api.dotnetstore.com/v1"; // เปลี่ยนค่าไม่ได้
let currentCartTotal = 0;                             // เปลี่ยนค่าได้

// 2. ข้อมูลแบบ Object และ Array
const course = {
  id: 101,
  title: "ASP.NET Core Web API",
  price: 2500,
  tags: ["C#", ".NET 8", "Backend"]
};

// 3. Arrow Function (ไวยากรณ์ฟังก์ชันลูกศรยุคใหม่)
const calculateDiscount = (price, percent) => {
  return price - (price * (percent / 100));
};

// 4. Template Literals (การต่อข้อความด้วย Backticks ` `)
const finalPrice = calculateDiscount(course.price, 10);
console.log(`คอร์ส ${course.title} ลดราคาเหลือเพียง: ${finalPrice} บาท ⚡`);

🌲 การเข้าถึงและแก้ไขหน้าเว็บ (DOM Manipulation & Events)

DOM (Document Object Model) คือต้นไม้โครงสร้างของ HTML ที่ JavaScript สามารถเข้าถึง เปลี่ยนข้อความ ซ่อน/แสดง หรือดักฟังเหตุการณ์การคลิกของผู้ใช้ได้ทันที

📜 dom-events.js 
// 1. ค้นหา Element จาก DOM
const buyBtn = document.getElementById('buyButton');
const statusText = document.querySelector('.status-message');
const counterLabel = document.querySelector('#cartCount');

let cartCount = 0;

// 2. ดักฟัง Event การคลิก (addEventListener)
buyBtn.addEventListener('click', (event) => {
  cartCount++;
  
  // แก้ไขข้อความในหน้าเว็บแบบ Real-time
  counterLabel.textContent = cartCount;
  statusText.innerHTML = `<strong style="color: #3fb950;">✓ เพิ่มลงตะกร้าสำเร็จแล้ว!</strong>`;
  
  // เพิ่ม/ลบ Class ของ CSS
  buyBtn.classList.add('btn-success');
  buyBtn.classList.remove('btn-primary');
});
🌐 การเชื่อมต่อ Backend API ด้วย Fetch & Async/Await

ในสถาปัตยกรรม Web สมัยใหม่ JavaScript จะทำหน้าที่ยิง HTTP Request ไปยัง ASP.NET Core Web API เพื่อดึงข้อมูล JSON มาแสดงผลบนหน้าจอโดยไม่ต้องรีโหลดหน้าเว็บใหม่ (AJAX / Single Page Application)

📜 api-service.js 
// ฟังก์ชันแบบ Asynchronous ดึงข้อมูลสินค้าจาก .NET Web API
async function fetchProductsFromDotNetApi() {
  const listContainer = document.getElementById('productList');
  
  try {
    listContainer.innerHTML = "<p>กำลังโหลดข้อมูลจาก Server...</p>";
    
    // ยิง HTTP GET ไปยัง Backend Endpoint
    const response = await fetch('/api/products');
    
    if (!response.ok) {
      throw new Error(`HTTP Error! Status: ${response.status}`);
    }
    
    // แปลง Response เป็น JSON Object
    const products = await response.json();
    
    // นำข้อมูลมาสร้าง HTML แสดงผล
    listContainer.innerHTML = products.map(item => `
      <div class="product-card">
        <h3>${item.name}</h3>
        <p class="price">฿${item.price.toLocaleString()}</p>
        <button onclick="addToCart(${item.id})" class="btn btn-sm btn-primary">ซื้อสินค้า</button>
      </div>
    `).join('');
    
  } catch (error) {
    console.error("เกิดข้อผิดพลาดในการโหลดข้อมูล:", error);
    listContainer.innerHTML = `<p class="text-danger">ไม่สามารถดึงข้อมูลได้: ${error.message}</p>`;
  }
}
🔄 Flow การทำงาน: Browser (Fetch) ─── HTTP GET /api/products ───▶ ASP.NET Core Controller (C#) ─── Return JSON ───▶ Browser JS Render HTML
