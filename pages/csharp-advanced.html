C# ขั้นกลาง-สูง: Async/Await, Generics & Null Safety

เจาะลึกฟีเจอร์สำคัญที่ใช้จริงในงาน Backend ระดับโปรดักชัน: Asynchronous Programming (Task, async/await), Generics & Constraints, Nullable Reference Types และ Delegates/Events

⭐ ระดับ: กลาง ⏱️ เวลา: ~60 นาที ⚡ รางวัล: +100 XP 🏷️ Task<T> / Generics / C# 12
👨‍🍳 เปรียบเทียบให้เห็นภาพ: เชฟทำอาหารในครัวยุคใหม่
💡 Analogy

• Synchronous (แบบเดิม): เชฟต้มน้ำซุปแล้ว ยืนรอเฉยๆ 15 นาทีจนน้ำเดือด ไม่ยอมทำอะไรต่อเลย ทำให้ครัวหยุดชะงัก (Blocking Thread)
• Asynchronous (async/await): เชฟตั้งหม้อน้ำซุปทิ้งไว้ (await BoilWaterAsync()) แล้ว ปล่อยมือไปหั่นผักและเตรียมเนื้อทันที เมื่อน้ำซุปเดือดสัญญาณเตือนดัง เชฟก็กลับมาทำต่อได้ โดยไม่ต้องใช้เชฟหลายคน (Non-blocking Thread Pool)
• Generics: เหมือน แม่พิมพ์ซิลิโคนอเนกประสงค์ ที่จะเทช็อกโกแลต เจลลี่ หรือน้ำแข็งลงไปก็ได้รูปทรงเดิมโดยไม่ต้องซื้อพิมพ์ใหม่แยกประเภท

01

Asynchronous Programming ด้วย async, await และ Task

ในงาน Backend API กว่า 90% เป็นงานประเภท I/O Bound (รอ Database ตอบกลับ, รออ่านไฟล์, รอดึงข้อมูลจาก Third-Party API) การใช้ Async/Await จะช่วยให้เซิร์ฟเวอร์รองรับ Concurrent Users ได้เพิ่มขึ้นเป็น 10 เท่า!

📄 AsyncExample.cs
public class OrderService
{
    private readonly ApplicationDbContext _db;
    private readonly IPaymentClient _payment;

    public OrderService(ApplicationDbContext db, IPaymentClient payment)
    {
        _db = db;
        _payment = payment;
    }

    // ✅ เมธอด async ต้องคืนค่าเป็น Task หรือ Task
    public async Task<OrderResult> ProcessOrderAsync(int orderId, CancellationToken cancellationToken = default)
    {
        // 1. ดึงข้อมูลจากฐานข้อมูลแบบ Asynchronous (ไม่บล็อก Thread)
        var order = await _db.Orders
            .FirstOrDefaultAsync(o => o.Id == orderId, cancellationToken);

        if (order == null) throw new NotFoundException("Order not found");

        // 2. เรียกตัดเงินผ่าน API ภายนอกแบบ Async
        var paymentResult = await _payment.ChargeAsync(order.TotalAmount, cancellationToken);

        order.Status = paymentResult.Success ? "Paid" : "Failed";

        // 3. บันทึกผลลัพธ์ลง Database
        await _db.SaveChangesAsync(cancellationToken);

        return new OrderResult { Success = paymentResult.Success };
    }
}

❌ ข้อห้ามเด็ดขาด (Async Anti-patterns)

  • ห้ามใช้ .Result หรือ .Wait(): เสี่ยงเกิด Thread Pool Deadlock ทันที!
  • หลีกเลี่ยง async void: ใช้ async Task เสมอ เพราะ async void ดักจับ Exception ไม่ได้ ยกเว้น UI Event Handlers

✅ Task.WhenAll (รันคู่ขนาน)

ถ้ารายการงานไม่ขึ้นต่อกัน สามารถยิงพร้อมกันด้วย Task.WhenAll() เพื่อความเร็วสูงสุด:

var userTask = _userService.GetAsync(id);
var ordersTask = _orderService.GetByUserIdAsync(id);

// รอให้ทั้งสองคำขอเสร็จพร้อมกัน
await Task.WhenAll(userTask, ordersTask);
02

Generics & Type Constraints (ความยืดหยุ่นและ Type Safety)

Generics ช่วยให้เราเขียน Class หรือ Method ที่ทำงานได้กับทุก Data Type โดยไม่ต้องทำ Boxing/Unboxing:

📄 GenericRepository.cs
// Generic Interface พร้อมกำหนด Constraint: T ต้องเป็น Class และเป็น EntityBase
public interface IRepository<T> where T : EntityBase, new()
{
    Task<T?> GetByIdAsync(int id);
    Task<IEnumerable<T>> GetAllAsync();
    Task AddAsync(T entity);
}

// Generic Implementation
public class Repository<T> : IRepository<T> where T : EntityBase, new()
{
    protected readonly ApplicationDbContext _context;
    protected readonly DbSet<T> _dbSet;

    public Repository(ApplicationDbContext context)
    {
        _context = context;
        _dbSet = _context.Set<T>();
    }

    public async Task<T?> GetByIdAsync(int id)
    {
        return await _dbSet.FindAsync(id);
    }
}
03

Modern Null Safety ใน C# (ป้องกัน NullReferenceException)

สัญลักษณ์ / Operator ชื่อเรียก ตัวอย่างโค้ด ผลลัพธ์ / การทำงาน
T? Nullable Reference Type string? nickname = null; บอก Compiler อย่างชัดเจนว่าตัวแปรนี้ "ยอมรับค่า null ได้"
?. Null-Conditional Operator int? length = user?.Address?.City?.Length; ถ้าตัวใดตัวหนึ่งเป็น null จะคืนค่า null ทันทีโดยไม่ Crash
?? Null-Coalescing Operator string display = user.Nickname ?? "สมาชิกทั่วไป"; ถ้าฝั่งซ้ายเป็น null ให้ใช้ค่าฝั่งขวาแทน
??= Null-Coalescing Assignment _cache ??= new Dictionary<string, string>(); ถ้าตัวแปรเป็น null ให้กำหนดค่าใหม่ทันที
! Null-Forgiving Operator var name = user.Name!; บอก Compiler ว่า "ฉันมั่นใจว่าไม่ใช่ null ไม่ต้องขึ้น Warning"
