Blazor Components, Lifecycle & State Management

สถาปัตยกรรม Component-based ใน Blazor, วงจรชีวิตของ Component (Lifecycle Methods), การส่งผ่านข้อมูลด้วย Parameters และ EventCallback, ฟอร์มและการตรวจสอบข้อมูล (EditForm)

⭐ ระดับ: กลาง ⏱️ เวลา: ~50 นาที ⚡ รางวัล: +100 XP 🏷️ OnInitializedAsync / EventCallback
🧱 เปรียบเทียบให้เห็นภาพ: ตัวต่อเลโก้อัจฉริยะ (Smart LEGO Bricks)
💡 Analogy

• Component: เหมือน บล็อกเลโก้ 1 ชิ้น ที่มีรูปทรงและการทำงานสมบูรณ์ในตัวเอง (HTML + C# Logic)
• [Parameter]: เหมือน ปุ่มตัวต่อด้านบน ที่รับคำสั่งหรือข้อมูลจากตัวต่อแม่ (Parent Component)
• EventCallback: เหมือน สัญญาณไฟแจ้งเตือน ที่ตัวต่อลูกส่งกลับไปบอกตัวต่อแม่ว่า "ผู้ใช้กดปุ่มแล้วนะ!"
• Lifecycle (OnInitializedAsync): เหมือน ช่วงเวลาเปิดสวิตช์เริ่มทำงานของเลโก้ เพื่อไปโหลดถ่านหรือดึงข้อมูลจาก Server

01

วงจรชีวิตของ Blazor Component (Lifecycle Methods)

เมื่อ Component ถูกแสดงผลบนหน้าจอ จะผ่านขั้นตอนการทำงานตามลำดับต่อไปนี้:

ลำดับ Lifecycle Method คำอธิบายและการใช้งาน ควรใช้ทำอะไร?
1 SetParametersAsync() รับค่า Parameters ที่ถูกส่งเข้ามาจาก Parent Component ประมวลผลค่าเริ่มต้นก่อน Render
2 OnInitialized() / OnInitializedAsync() ทำงานเพียง ครั้งเดียว เมื่อ Component ถูกสร้างขึ้น ดึงข้อมูลจาก API / Database (สำคัญที่สุด!)
3 OnParametersSetAsync() ทำงานเมื่อได้รับค่า Parameter ใหม่ หรือ URL Route เปลี่ยน อัปเดตข้อมูลเมื่อ ID ใน URL เปลี่ยนแปลง
4 OnAfterRenderAsync(bool firstRender) ทำงาน หลัง จากที่ HTML เรนเดอร์บน Browser เสร็จแล้ว เรียกคำสั่ง JavaScript Interop (JSInterop)
5 Dispose() / DisposeAsync() ทำงานเมื่อ Component ถูกปิดหรือเปลี่ยนหน้า Unsubscribe C# Events และคืนทรัพยากร Memory
02

การสื่อสารระหว่าง Components ([Parameter] & EventCallback)

📄 ProductCard.razor (Child Component)
<div class="card">
    <h4>@Title</h4>
    <p>ราคา: @Price.ToString("C")</p>
    <button class="btn btn-primary" @onclick="HandleAddToCart">
        🛒 เพิ่มลงตะกร้า
    </button>
</div>

@code {
    // 1. รับข้อมูลจาก Parent
    [Parameter]
    public string Title { get; set; } = string.Empty;

    [Parameter]
    public decimal Price { get; set; }

    // 2. ส่ง Event กลับไปหา Parent
    [Parameter]
    public EventCallback<string> OnAddToCart { get; set; }

    private async Task HandleAddToCart()
    {
        // แจ้ง Parent ว่ามีการเพิ่มสินค้านี้
        await OnAddToCart.InvokeAsync(Title);
    }
}
03

การสร้างฟอร์มและการตรวจสอบข้อมูลด้วย EditForm

Blazor มีระบบ <EditForm> ที่ผูกกับ Data Annotations ของ C# โดยตรง:

📄 CreateUserForm.razor
@using System.ComponentModel.DataAnnotations

<EditForm Model="@userModel" OnValidSubmit="HandleSubmit">
    <!-- ตรวจสอบความถูกต้องตาม C# Data Annotations -->
    <DataAnnotationsValidator />
    <ValidationSummary />

    <div class="form-group mb-md">
        <label>ชื่อผู้ใช้:</label>
        <InputText @bind-Value="userModel.Username" class="form-control" />
        <ValidationMessage For="@(() => userModel.Username)" />
    </div>

    <div class="form-group mb-md">
        <label>อีเมล:</label>
        <InputText @bind-Value="userModel.Email" class="form-control" />
        <ValidationMessage For="@(() => userModel.Email)" />
    </div>

    <button type="submit" class="btn btn-success">บันทึกข้อมูล</button>
</EditForm>

@code {
    private UserModel userModel = new();

    private void HandleSubmit()
    {
        // ทำงานเมื่อข้อมูลถูกต้องครบถ้วนเท่านั้น (Valid Submit)
        Console.WriteLine($"สร้างผู้ใช้ {userModel.Username} สำเร็จ!");
    }

    public class UserModel
    {
        [Required(ErrorMessage = "กรุณากรอกชื่อผู้ใช้")]
        [StringLength(20, MinimumLength = 3, ErrorMessage = "ชื่อต้องมีความยาว 3-20 ตัวอักษร")]
        public string Username { get; set; } = string.Empty;

        [Required(ErrorMessage = "กรุณากรอกอีเมล")]
        [EmailAddress(ErrorMessage = "รูปแบบอีเมลไม่ถูกต้อง")]
        public string Email { get; set; } = string.Empty;
    }
}
