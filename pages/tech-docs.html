Technical Documentation & Swagger / OpenAPI

การเขียนเอกสารทางเทคนิคสำหรับระบบซอฟต์แวร์, การสร้าง API Documentation อัตโนมัติด้วย Swagger/OpenAPI, C# XML Comments และการเขียน README.md ระดับมืออาชีพ

⭐ ระดับ: พื้นฐาน ⏱️ เวลา: ~35 นาที ⚡ รางวัล: +100 XP 🏷️ Swagger / XML Comments / Markdown
🗺️ เปรียบเทียบให้เห็นภาพ: แผนที่นำทางและคู่มือประกอบเฟอร์นิเจอร์
💡 Analogy

• โค้ดที่ไม่มีเอกสาร: เหมือน เฟอร์นิเจอร์ IKEA ที่มีแต่น็อต 500 ตัวแต่ไม่มีคู่มือ — แม้ของจะดีแค่ไหน คนอื่น (หรือตัวเราเองในอีก 6 เดือนข้างหน้า) ก็ไม่รู้ว่าจะประกอบและใช้งานอย่างไร
• Swagger / OpenAPI: เหมือน ตู้จำหน่ายสินค้าอัตโนมัติที่มีเมนูและปุ่มกดทดลองกดได้จริง — Frontend และ Third-Party สามารถทดลองส่ง Parameter และดู Response Schema ได้ทันทีโดยไม่ต้องถาม Backend Developer

C# XML Documentation Comments (///)

เมื่อพิมพ์ /// เหนือ Class หรือ Method ใน Visual Studio จะสร้างโครงสร้าง XML Document ที่แสดงผลใน IntelliSense และแปลงเป็น Swagger UI อัตโนมัติ:

📄 ProductsController.cs (XML Documentation)
/// <summary>
/// ค้นหาข้อมูลสินค้าตามรหัสประจำตัว (ID)
/// </summary>
/// <param name="id">รหัสประจำตัวของสินค้าที่ต้องการค้นหา</param>
/// <returns>ส่งกลับข้อมูล ProductResponseDto พร้อมรหัสสถานะ 200 OK</returns>
/// <response code="200">ค้นพบสินค้าสำเร็จ</response>
/// <response code="404">ไม่พบสินค้าตาม ID ที่ระบุ</response>
[HttpGet("{id:int}")]
[ProducesResponseType(typeof(ProductResponseDto), StatusCodes.Status200OK)]
[ProducesResponseType(StatusCodes.Status404NotFound)]
public async Task<ActionResult<ProductResponseDto>> GetById(int id)
{
    var product = await _service.GetByIdAsync(id);
    if (product == null) return NotFound();
    return Ok(product);
}

# 🚀 MyShop E-Commerce Web API (.NET 9)

ระบบ Backend RESTful API สำหรับแพลตฟอร์มจำหน่ายสินค้าออนไลน์ พัฒนาด้วย ASP.NET Core 9 และ EF Core

## 🛠️ Tech Stack & Prerequisites
- .NET SDK 9.0+
- Microsoft SQL Server 2022 / Azure SQL
- Docker Desktop

## ⚙️ Getting Started (วิธีรันโปรเจกต์)
1. Clone Repository:
   ```bash
   git clone https://github.com/myorg/myshop-api.git
   cd myshop-api
   ```
2. Restore NuGet Packages & Build:
   ```bash
   dotnet restore
   dotnet build
   ```
3. Update Database Migrations:
   ```bash
   dotnet ef database update
   ```
4. Run Application:
   ```bash
   dotnet run --project MyShop.Api
   ```
5. เปิดเบราว์เซอร์เข้าใช้งาน Swagger UI: `https://localhost:7001/swagger`
