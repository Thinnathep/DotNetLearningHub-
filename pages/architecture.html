Clean Architecture & Enterprise Patterns ใน .NET

สถาปัตยกรรมระดับองค์กร (Clean Architecture / Onion Architecture), การแบ่ง 4 เลเยอร์มาตรฐาน, Repository Pattern, CQRS และ MediatR

⭐ ระดับ: กลาง ⏱️ เวลา: ~50 นาที ⚡ รางวัล: +100 XP 🏷️ Clean Architecture / CQRS / MediatR
🧅 เปรียบเทียบให้เห็นภาพ: หัวหอมและกำแพงเมืองโบราณ
💡 Analogy

• Domain Layer (แก่นกลางหัวหอม): เหมือน พระราชวังชั้นในสุด ที่มีกฎทางธุรกิจ (Business Rules/Entities) บริสุทธิ์ที่สุด ไม่ขึ้นต่อใครเลย ไม่รู้ด้วยซ้ำว่าข้างนอกใช้ Database อะไร
• Application Layer: เหมือน เหล่าขุนนางที่ดูแลคำสั่งราชการ (Use Cases / CQRS Handlers) กำหนดว่าเมื่อมีคำสั่งซื้อเกิดขึ้น ต้องทำอะไรตามลำดับ
• Infrastructure Layer: เหมือน กองทหารขนส่งและคลังอาวุธ เชื่อมต่อกับโลกภายนอก (SQL Server, Email Server, Third-Party API)
• Presentation / API Layer (เปลือกนอกสุด): เหมือน ประตูเมืองและตลาดรับแขก (Controllers, Swagger) รับคำขอจากลูกค้าแล้วส่งต่อเข้าวัง

📐 กฎ Dependency Rule ของ Clean Architecture

การพึ่งพา (Dependency) ต้องชี้เข้าสู่ด้านในเสมอ! เลเยอร์ชั้นใน (Domain & Application) ต้อง ไม่มีการอ้างอิง (Reference) ไปยังเลเยอร์ชั้นนอก (Infrastructure หรือ Presentation) เลยเด็ดขาด

CQRS Pattern (Command Query Responsibility Segregation) & MediatR

CQRS แยกการทำงานระหว่าง คำสั่งแก้ไขข้อมูล (Command) และ คำขอดึงข้อมูล (Query) ออกจากกันเพื่อความสะอาดและ Scale ง่าย:

📄 CreateProductCommand.cs (MediatR Example)
// 1. Command (ข้อมูลคำขอสร้างสินค้า)
public record CreateProductCommand(string Name, decimal Price, int Stock) : IRequest<int>;

// 2. Command Handler (Logic การประมวลผลคำสั่ง)
public class CreateProductCommandHandler : IRequestHandler<CreateProductCommand, int>
{
    private readonly ApplicationDbContext _db;

    public CreateProductCommandHandler(ApplicationDbContext db)
    {
        _db = db;
    }

    public async Task<int> Handle(CreateProductCommand request, CancellationToken cancellationToken)
    {
        var product = new Product
        {
            Name = request.Name,
            Price = request.Price,
            Stock = request.Stock
        };

        _db.Products.Add(product);
        await _db.SaveChangesAsync(cancellationToken);

        return product.Id; // ส่ง ID ที่สร้างกลับไป
    }
}
