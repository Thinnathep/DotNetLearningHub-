🏢 Aware Group — Company Research & Interview Playbook

เจาะลึกโครงสร้างองค์กร Aware Group, กระบวนการคัดเลือกและสอบสัมภาษณ์ 3 ด่าน (Screening ➔ Test ➔ Tech Lead), เทคโนโลยีหลัก (.NET, C#, SQL Server, Azure) และแนวทางตอบคำถามเพื่อคว้างานแรกของคุณ!

01

🏢 ข้อมูลบริษัท & ดีเอ็นเอขององค์กร (Company DNA)

🌍 ขนาดและความน่าเชื่อถือ

หนึ่งในบริษัทผู้นำด้าน Software Development & IT Professional Services ชั้นนำในไทย มีวิศวกรซอฟต์แวร์กว่า 1,000+ คน และมีสำนักงานใน กรุงเทพฯ, เชียงใหม่ และเชียงราย

💼 บริการหลัก (Core Business)

พัฒนา Enterprise Custom Software, Cloud Modernization (.NET & Microsoft Azure), Outsourcing Solution, Data & AI Integration, และ QA Software Testing

🤝 วัฒนธรรม (Work Culture)

เน้นการทำงานเป็นทีม (Agile/Scrum), เปิดรับคนรุ่นใหม่และผู้เปลี่ยนสายงาน (Career Changers) ที่มีความกระตือรือร้นและพร้อมเรียนรู้สิ่งใหม่เสมอ

02

🎯 กระบวนการสัมภาษณ์ 3 ด่านของ Aware Group

📞 ด่านที่ 1: Initial Telephone Screening (ฝ่ายบุคคล)

15 - 30 นาที

Recruiter จะติดต่อกลับหลังส่งเรซูเม่ (โดยทั่วไปภายใน 2 วันทำการ) เพื่อสอบถามประวัติการศึกษา, ความสนใจในสาย .NET, ความพร้อมในการทำงาน และการสื่อสารภาษาอังกฤษเบื้องต้น

💻 ด่านที่ 2: Technical Assessment & Coding Test

1 - 2 ชั่วโมง

ทำแบบทดสอบทางเทคนิค: ข้อสอบวัดความเข้าใจ C# (.NET Core, OOP, Data Types), SQL Server (CRUD, JOINs, Query Optimization), และ Logic Testing เช่น การดักจับ Edge Cases และการเขียน Web API

🎙️ ด่านที่ 3: Technical Hiring Manager & Team Interview

45 - 60 นาที

สัมภาษณ์กับ Tech Lead / Engineering Manager (1–3 ท่าน) เพื่อพูดคุยเกี่ยวกับโค้ดที่ทำในข้อสอบ, ความเป็นเจ้าของโค้ด (Code Ownership), สถาปัตยกรรม Clean Architecture, และทดสอบ Culture Fit การทำงานเป็นทีม

03

💎 ทักษะหลักที่ Aware Group มองหาในตัว Junior .NET

⚡ C# & ASP.NET Core

  • เข้าใจ OOP 4 เสาหลัก (Encapsulation, Inheritance, Polymorphism, Abstraction)
  • ใช้งาน async / await แบบ Non-blocking ได้อย่างถูกต้อง
  • เข้าใจ Dependency Injection (Transient, Scoped, Singleton)

🗄️ Database & RESTful APIs

  • เขียนคำสั่ง SQL (JOINs, GROUP BY, Indexing)
  • ใช้งาน Entity Framework Core (DbContext, Eager Loading .Include, AsNoTracking)
  • ออกแบบ RESTful API มาตรฐาน (HTTP Verbs, DTOs, Status Codes)
04

🎙️ แนวทางการตอบคำถามสัมภาษณ์เฉพาะของ Aware Group

Q: "ทำไมคุณถึงสนใจร่วมงานกับ Aware Group?"

แนวทางตอบระดับ Senior:

"ผมติดตามผลงานของ Aware Group ในฐานะผู้นำด้าน Enterprise Software Services และ Cloud Modernization ของไทยมาโดยตลอดครับ ผมประทับใจในวัฒนธรรมที่สนับสนุนการเติบโตของทีม (Continuous Learning) และความเชี่ยวชาญในระบบนิเวศของ .NET Core & Microsoft Azure ซึ่งตรงกับเป้าหมายของผมที่ต้องการพัฒนาตัวเองเป็นวิศวกรซอฟต์แวร์คุณภาพในระดับองค์กรครับ"

Q: "ถ้าคุณเจอบัคยากๆ ในงานที่คุณไม่เคยเจอมาก่อน คุณมีกระบวนการแก้อย่างไร?"

แนวทางตอบ (STAR Method):

"ผมจะเริ่มจากการอ่าน Error Log และ Reproduction Step ให้ชัดเจนก่อนครับ จากนั้นใช้ Debugger ไล่ Breakpoint ตรวจสอบ Data State และหากเป็นเรื่องใหม่ ผมจะศึกษาจาก Official Microsoft Documentation หรือใช้ AI ช่วยวิเคราะห์หาสาเหตุของปัญหา จากนั้นเขียน Unit Test เพื่อพิสูจน์ว่าบัคได้รับการแก้ไขอย่างแท้จริงโดยไม่กระทบส่วนอื่นครับ"

Q: "มีคำถามอะไรอยากถามกรรมการไหมครับ?"

คำถามเพิ่มคะแนนที่ควรถามกลับ:

1. "ในทีมที่ผมจะได้เข้าไปร่วมงาน ปัจจุบันใช้ .NET เวอร์ชันใด (เช่น .NET 8 หรือ .NET 9) และมีแนวทางการทำ CI/CD อย่างไรครับ?"
2. "กระบวนการทำ Code Review และการแชร์ความรู้ (Knowledge Sharing) ในทีมมีรูปแบบอย่างไรบ้างครับ?"
