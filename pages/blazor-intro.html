สร้าง Rich Interactive Web Applications ด้วยภาษา C# และ .NET แทนการเขียน JavaScript! เรียนรู้เบื้องลึกของ 3 Hosting Models, ไวยากรณ์ Razor Syntax, Two-way Data Binding และการจัดการ State

⭐ ระดับ: พื้นฐาน > กลาง ⏱️ เวลา: ~45 นาที ⚡ รางวัล: +100 XP 🏷️ WebAssembly / Blazor Server / Razor / .NET 8

💡 Deep Concept Analogy

ในโลกการพัฒนาเว็บแบบดั้งเดิม Frontend (หน้าบ้าน) และ Backend (หลังบ้าน) เปรียบเหมือน สองเมืองที่อยู่คนละฝั่งแม่น้ำ และพูดคนละภาษา — ฝั่งหน้าบ้านพูดภาษา JavaScript/TypeScript ส่วนฝั่งหลังบ้านพูดภาษา C# คุณต้องสร้างสะพานและคอยเขียนตัวแปลภาษา (DTOs/Interfaces) ซ้ำซ้อนสองรอบ!

⚡ Blazor คือสะพานเชื่อมสองฝั่งแม่น้ำ ที่ทำให้ทั้งหน้าบ้านและหลังบ้าน พูดภาษา C# เดียวกัน 100% คุณสามารถแชร์ Data Models, Validation Logic และคลาสต่างๆ ข้ามฝั่งได้ทันทีโดยไม่ต้อง Context Switch หรือเรียนรู้ Framework ฝั่ง JS อีกต่อไป!

Blazor คืออะไร? และ 3 Hosting Models ในโลกจริง

Blazor (Browser + Razor) เป็น Web Framework โอเพนซอร์สจาก Microsoft ที่ช่วยให้นักพัฒนาสามารถสร้าง Single Page Applications (SPA) และเว็บแอปพลิเคชันที่มีการโต้ตอบสูง (Interactive Web UI) โดยใช้ C# และ HTML/CSS โดยตรง ไม่ต้องพึ่งพา React, Angular หรือ Vue.js

⚡

Blazor WebAssembly

Client-Side (WASM)

ดาวน์โหลด .NET WebAssembly Runtime และไฟล์ .dll ของโค้ด C# มารันใน Browser ของผู้ใช้โดยตรงแบบ 100% Client-side execution

  • Offline Support: ทำงานแบบ PWA หรือ Offline ได้เต็มรูปแบบ
  • Zero Server Load: งานประมวลผล UI เกิดที่ CPU ผู้ใช้ เซิร์ฟเวอร์ทำหน้าที่แค่ Static File Host
  • Static Hosting: สามารถโฮสต์บน GitHub Pages, AWS S3, Azure Blob ได้ทันที
  • Initial Load Time: หน้าแรกใช้เวลาดาวน์โหลด WASM runtime นานกว่าปกติ (~2-5 MB)
  • Code Visibility: โค้ด .dll ถูกโหลดไปที่เครื่อง Client (ไม่ควรใส่ความลับ/Connection String)
🖥️

Blazor Server

Real-Time SignalR

โค้ด C# ทั้งหมดรันบน Server ฝั่ง Browser มีเพียง HTML เบาๆ ที่สื่อสารผ่าน Real-time WebSocket (SignalR) เพื่ออัปเดตเฉพาะ DOM Diff

  • Fast Initial Load: โหลดหน้าแรกไวมาก ไม่ต้องดาวน์โหลด .NET runtime ขนาดใหญ่
  • High Security: โค้ดและ Business Logic ไม่เคยหลุดออกจาก Server
  • Full .NET API: เรียกใช้ Database, Services ภายในเครื่อง Server ได้โดยตรง
  • Network Latency: ทุกการคลิกต้องส่งผ่าน SignalR จึงรู้สึกดีเลย์ถ้าเน็ตช้า
  • Server Resource: ต้องเปิด WebSocket ค้างไว้ กิน RAM ตามจำนวน Active User
🚀

Blazor Web App (.NET 8/9)

Full-Stack SSR + Auto Mode

มาตรฐานใหม่รวมทุกจุดเด่นเข้าด้วยกัน! โหลดหน้าแรกด้วย Static Server-Side Rendering (SSR) แล้วสลับเป็น WebAssembly ทันทีในพื้นหลัง

  • Best of Both Worlds: หน้าแรกโหลดเร็วระดับมิลลิวินาที (SSR) + การโต้ตอบลื่นไหล (WASM)
  • Interactive Auto Mode: รันบน Server ชั่วคราวระหว่างรอ WASM ดาวน์โหลดเสร็จ
  • SEO Friendly: Search Engine Bot อ่านเนื้อหา HTML ได้ครบถ้วนสมบูรณ์
  • Per-Component Render Mode: เลือก Render Mode แยกเฉพาะ Component แต่ละตัวได้อิสระ

📊 ตารางเปรียบเทียบข้อดี-ข้อเสียของแต่ละ Hosting Model

คุณสมบัติ (Feature) ⚡ Blazor WebAssembly 🖥️ Blazor Server 🚀 Blazor Web App (Auto / .NET 8)
ตำแหน่งที่โค้ดรัน (Code Execution) ใน Web Browser ผ่าน WebAssembly บน ASP.NET Core Server Server SSR ก่อน แล้วสลับเป็น Client WASM
ความเร็วในการโหลดครั้งแรก ช้ากว่า (ต้องดาวน์โหลด WASM runtime) เร็วมาก (ส่ง Pure HTML/JS เล็กๆ) เร็วที่สุด (Static SSR ทันที)
การใช้งานเมื่อไม่มีอินเทอร์เน็ต (Offline) รองรับสมบูรณ์ (PWA) ไม่รองรับ (ต้องต่อเน็ต) รองรับเมื่อ WASM โหลดเสร็จ
ภาระทรัพยากรบน Server (Server Load) แทบเป็น 0 (Server แค่เสิร์ฟ Static Files) สูง (ต้องจำ State และเปิด WebSocket) ยืดหยุ่น ปรับแต่งตามโหมดที่เลือก
ความปลอดภัยของโค้ด (IP Protection) ปานกลาง (ไฟล์ .dll อยู่ฝั่ง Client) สูงสุด (โค้ดอยู่บน Server ทั้งหมด) สูงสุดในส่วน Server Components
กรณีการใช้งานที่เหมาะสมที่สุด แอปพลิเคชัน Offline, Dashboard, Internal Tools Enterprise Web Apps, Intranet องค์กร Public Website, E-Commerce, SaaS ยุคใหม่

ไวยากรณ์ Razor Syntax: การผสมผสาน HTML + C#

ไฟล์คอมโพเนนต์ของ Blazor จะมีนามสกุลเป็น .razor ซึ่งใช้ไวยากรณ์ Razor Syntax โดยมีหัวใจสำคัญคือเครื่องหมาย @ (At Sign) ที่ใช้เป็นตัวสลับโหมดจากการเขียน HTML เข้าสู่โลกของภาษา C# อย่างราบรื่น

@ Direct Expression

แทรกค่าจากตัวแปร C# หรือ Expression ลงใน HTML เช่น <h1>@userName</h1> หรือ <p>@DateTime.Now.Year</p>

@( ... ) Explicit Expression

คำนวณสูตรหรือเรียกใช้ Expression แบบชัดเจน เช่น <p>ราคารวม: @(price * 1.07m) บาท</p>

@if (...) { } Control Flow

แสดงผล DOM ตามเงื่อนไข เช่น ตรวจสอบสถานะ Login หรือการโหลดข้อมูล @if (isLoading) { <Spinner /> }

@foreach (...) { } Loop

วนลูปเรนเดอร์ Element ซ้ำๆ จาก Collection หรือ List เช่น วนลูปตารางสินค้า หรือแสดงรายการ Todo Item

@code { ... } State & Logic

บล็อกหลักสำหรับเขียนตัวแปร State, Properties, Methods, และ Event Handlers ทางภาษา C# ภายในไฟล์ .razor

@page "/route" Routing

กำหนดให้ Component นี้กลายเป็นหน้าเว็บ (Page) ที่เข้าถึงได้ผ่าน URL Path เช่น @page "/products"

📄 UserProfile.razor — โครงสร้างมาตรฐานของ Razor Component 
@page "/profile/{UserId:int}"
@inject HttpClient Http

<div class="user-card">
    <h2>โปรไฟล์ผู้ใช้: @userName</h2>
    
    @* การใช้เงื่อนไขตรวจสอบสถานะ *@
    @if (isVipMember)
    {
        <span class="badge badge-gold">👑 สมาชิก VIP</span>
    }
    else
    {
        <span class="badge badge-normal">👤 สมาชิกทั่วไป</span>
    }

    <h3>ทักษะที่เชี่ยวชาญ:</h3>
    <ul>
        @* การวนลูปเรนเดอร์รายการ *@
        @foreach (var skill in skills)
        {
            <li>⚡ @skill</li>
        }
    </ul>

    <button class="btn btn-primary" @onclick="UpgradeToVip">
        อัปเกรดเป็น VIP
    </button>
</div>

@code {
    [Parameter]
    public int UserId { get; set; }

    private string userName = "สมชาย สายโค้ด";
    private bool isVipMember = false;
    private List<string> skills = new() { "C#", "ASP.NET Core", "Blazor", "SQL" };

    private void UpgradeToVip()
    {
        isVipMember = true;
    }
}
💡 คำสั่ง Directives ที่สำคัญอื่นๆ ใน Blazor
  • @inject ISomeService Service — ดึง Dependency Injection Service มาใช้งานในคอมโพเนนต์
  • @using MyProject.Models — Import Namespace ที่ต้องการ
  • @attribute [Authorize] — กำหนดสิทธิ์ความปลอดภัยในการเข้าถึงหน้า
  • @rendermode InteractiveServer หรือ InteractiveWebAssembly — กำหนด Render Mode ใน .NET 8

Event Handling & Data Binding (การจัดการอีเวนต์และการผูกข้อมูล)

ใน Blazor การติดต่อระหว่าง HTML Controls และตัวแปรใน C# ถูกจัดการผ่านระบบ Data Binding และ Event Handling อย่างเป็นธรรมชาติและทรงพลัง

1️⃣ One-way Data Binding

ข้อมูลส่งทิศทางเดียวจาก C# State ➔ HTML DOM เมื่อค่าใน C# เปลี่ยน หน้าจอจะเปลี่ยนตาม แต่ถ้าผู้ใช้แก้ไขค่าในหน้าจอ ตัวแปรใน C# จะ ไม่เปลี่ยน 

<!-- แสดงผลข้อความธรรมดา -->
<p>สวัสดีคุณ @currentUser</p>

<!-- กำหนด Attribute ให้ input (ไม่เปลี่ยนค่ากลับ) -->
<input type="text" value="@currentUser" />

2️⃣ Two-way Data Binding (`@bind`)

ข้อมูลเชื่อมต่อสองทาง C# State ⇄ HTML DOM เมื่อตัวแปร C# เปลี่ยน ค่าบนจอเปลี่ยน และเมื่อผู้ใช้พิมพ์แก้ไขในช่อง Input ตัวแปรใน C# จะ อัปเดตอัตโนมัติ 

<!-- Two-way Binding แบบมาตรฐาน (อัปเดตเมื่อ onchange) -->
<input @bind="searchKeyword" />

<!-- Two-way Binding แบบ Real-time ทันทีที่พิมพ์ -->
<input @bind="searchKeyword" @bind:event="oninput" />

🎯 Event Handling ใน Blazor

เราสามารถผูก HTML Events เช่น onclick, onchange, onkeydown เข้ากับ Method ภาษา C# โดยใส่เครื่องหมาย @ นำหน้า:

⚡ ตัวอย่างรูปแบบการผูก Event หลากหลายสไตล์ 
@* 1. เรียก Method ตรงๆ โดยไม่มี Parameter *@
<button @onclick="SaveData">บันทึก</button>

@* 2. ส่ง Parameter ผ่าน Lambda Expression *@
<button @onclick="() => DeleteProduct(product.Id)">ลบสินค้านี้</button>

@* 3. รับ Event Arguments เช่น MouseEventArgs หรือ KeyboardEventArgs *@
<div @onclick="HandleClickCoordinates">คลิกเพื่อดูพิกัด X, Y</div>
<input @onkeydown="HandleKeyPress" placeholder="กดปุ่มบนคีย์บอร์ด..." />

@code {
    private void SaveData() { /* ทำงานเมื่อคลิก */ }
    private void DeleteProduct(int id) { /* ลบสินค้าตาม ID */ }
    
    private void HandleClickCoordinates(MouseEventArgs e)
    {
        Console.WriteLine($"คลิกที่พิกัด: X={e.ClientX}, Y={e.ClientY}");
    }

    private void HandleKeyPress(KeyboardEventArgs e)
    {
        if (e.Key == "Enter") {
            Console.WriteLine("ผู้ใช้กดปุ่ม Enter!");
        }
    }
}

ห้องทดลองเสมือน: Blazor Component Sandbox Live Simulator

ทดลองสังเกตการทำงานของ State และ Data Binding ใน Blazor แบบเสมือนจริง ลองกดปุ่มหรือพิมพ์ในช่อง Input ด้านขวา เพื่อดูการเปลี่ยนแปลงค่าตัวแปรในโค้ด C# ทางด้านซ้าย!

⚡ Blazor Component Live Visualizer 
@page "/counter"

<h3>ตัวนับจำนวน (Counter)</h3>

<p>ค่าปัจจุบัน: <strong>@currentCount</strong></p>

<button class="btn btn-primary" @onclick="IncrementCount">
    + เพิ่มจำนวน
</button>
<button class="btn btn-outline" @onclick="DecrementCount">
    - ลดจำนวน
</button>
<button class="btn btn-ghost" @onclick="ResetCount">
    รีเซ็ต
</button>

@code {
    // C# Component State
    private int currentCount = 0;

    private void IncrementCount()
    {
        currentCount++;
    }

    private void DecrementCount()
    {
        if (currentCount > 0) currentCount--;
    }

    private void ResetCount()
    {
        currentCount = 0;
    }
}
@page "/todo"

<h3>รายการสิ่งที่ต้องทำ (Todo List)</h3>

<div class="input-group">
    <input @bind="newTodoText" placeholder="พิมพ์งานใหม่..." />
    <button @onclick="AddTodo">+ เพิ่ม</button>
</div>

<ul>
    @foreach (var todo in todos)
    {
        <li>
            <input type="checkbox" @bind="todo.IsDone" />
            <span class="@(todo.IsDone ? "done" : "")">@todo.Title</span>
        </li>
    }
</ul>

@code {
    private string newTodoText = "";
    private List<TodoItem> todos = new()
    {
        new TodoItem { Title = "เรียน Blazor พื้นฐาน", IsDone = true },
        new TodoItem { Title = "ทำแบบฝึกหัด 5 ข้อ", IsDone = false }
    };

    private void AddTodo()
    {
        if (!string.IsNullOrWhiteSpace(newTodoText))
        {
            todos.Add(new TodoItem { Title = newTodoText, IsDone = false });
            newTodoText = ""; // Clear input
        }
    }
}
